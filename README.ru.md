# Суфлёр (Prompter) для macOS

Подсказчик для разговора на иностранном языке. Суфлёр слушает вас и собеседника. Когда вы запинаетесь посреди фразы, он показывает в плавающем окне облако подходящих слов и 2–3 готовых продолжения фразы с учётом вашего проекта.

## Что умеет MVP

- **Расшифровка в реальном времени** двух каналов: «я» (микрофон) и «собеседник» (системный звук Zoom/Meet/Teams/браузера). Распознавание идёт на устройстве через SpeechAnalyzer, бесплатно и офлайн.
- **Детектор «зависания»** срабатывает на паузу после незаконченной фразы или на слово-паразит («um», «эээ»). Подсказку можно вызвать и вручную: **⌥⌘Space** из любого приложения.
- **Облако слов и фразы.** Размер слова зависит от релевантности. Клик по слову или фразе копирует его. Если вы сказали слово по-русски, первым будет его перевод.
- **Две модели параллельно.** Локальная Apple Intelligence отвечает быстро и бесплатно. Claude, если указан ключ, отвечает точнее с полным контекстом проекта и заменяет локальный ответ, когда приходит.
- **База знаний (RAG).** Описание проекта, глоссарий («выкатка = rollout») и документы (txt/md/pdf/docx/код). Документы режутся на фрагменты и векторизуются локально (NaturalLanguage), поиск гибридный: векторы плюс ключевые слова.
- **Субтитры с переводом** реплик собеседника на родной язык через встроенный переводчик macOS.
- **История.** После созвона видно, где вы запнулись и какие слова повторить, есть экспорт в Markdown.
- Окно подсказок не забирает фокус и пытается скрыться от демонстрации экрана.

## Запуск

Нужны macOS 26+ и Xcode 26+.

```bash
brew install xcodegen        # если ещё не установлен
git clone https://github.com/aleksabramov77/prompter-macos.git && cd prompter-macos
xcodegen generate
open Prompter.xcodeproj      # затем ⌘R в Xcode
```

Или без Xcode-интерфейса:

```bash
xcodebuild -project Prompter.xcodeproj -scheme Prompter -derivedDataPath build build
open build/Build/Products/Debug/Prompter.app
```

Тесты: `xcodebuild test -project Prompter.xcodeproj -scheme Prompter -destination 'platform=macOS' -derivedDataPath build`.

### Первый запуск

1. Вкладка **Настройки**: выберите язык речи и родной язык. Для подсказок от Claude вставьте API-ключ с console.anthropic.com. Без ключа работает только Apple Intelligence (нужно включить её в Системных настройках).
2. Вкладка **Знания**: пара абзацев о проекте, глоссарий и, по желанию, папка с документами.
3. **Начать сессию**. macOS попросит доступ к микрофону, а при включённом «Слушать собеседника» — к записи экрана и системного звука. После выдачи доступа к записи экрана приложение нужно перезапустить.
4. Наденьте наушники. Без них голос собеседника из динамиков попадёт в микрофон как ваш.

> Без Team ID в `project.yml` приложение подписывается ad-hoc, и macOS может заново спрашивать разрешения после каждой пересборки. Чтобы этого не было, укажите `DEVELOPMENT_TEAM`.

## Приватность

- Звук не сохраняется. Распознавание речи, эмбеддинги и локальная модель работают на Mac.
- В Claude (только если указан ключ) уходят описание проекта, релевантные термины глоссария, до 4 найденных фрагментов документов и последние ~2000 символов разговора.
- Ключ хранится в Связке ключей. Данные приложения лежат в `~/Library/Application Support/Prompter`.
- Записывать собеседника без согласия в ряде стран незаконно, поэтому предупреждайте собеседника.

## Устройство

```
Prompter/
  App/        AppModel (координатор), AppSettings, точка входа и меню
  Core/       чистая логика с тестами: детектор зависания, транскрипт, чанкер, векторный индекс,
              промпты, разбор ответа модели, история сессий
  Audio/      микрофон (AVAudioEngine) и системный звук (ScreenCaptureKit)
  Speech/     потоковое распознавание (SpeechAnalyzer/SpeechTranscriber)
  AI/         Claude Messages API, Apple Foundation Models, перевод субтитров
  Knowledge/  база знаний: чтение файлов, эмбеддинги, поиск
  UI/         окно подсказок, вкладки главного окна
PrompterTests/  Swift Testing, 38 тестов на Core
```
